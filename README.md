Sistema Distribuido de Gestión de Procesos y Monitoreo
Este proyecto consiste en una aplicación de arquitectura distribuida diseñada para la supervisión y control de procesos en sistemas operativos remotos. Utiliza una estructura de tres niveles (Cliente-Middleware-Servidor) para facilitar la administración de múltiples nodos a través de una red local mediante sockets TCP/IP.
Características Principales
Gestión de Procesos: Listado detallado, inicio de aplicaciones y finalización de procesos por PID.

Monitoreo de Recursos: Visualización en tiempo real del uso de CPU y memoria RAM del servidor.

Arquitectura Distribuida: Middleware integrado para el descubrimiento de servicios y gestión de múltiples servidores remotos.

Comunicación Robusta: Protocolo basado en Sockets TCP para asegurar la integridad de los comandos enviados.
